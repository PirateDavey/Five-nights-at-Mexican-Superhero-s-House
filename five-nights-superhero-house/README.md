# Five Nights at Mexican Superhero's House

A survival-horror fan game in the classic "stay alive until 6 AM" style. You're the new night
guard at a very lively house. The masked heroes wander around after midnight. Watch the cameras,
manage your power, and shut the doors in time.

> **Unofficial fan game.** Not affiliated with or endorsed by the creators of Five Nights at
> Freddy's. All characters, art and sound in this repo are original and generated by code, so
> there are no image or audio files in the repository.

## The heroes

| Who | Behaviour |
|---|---|
| **El Trueno** | Green-and-gold luchador. Works his way through the house to your **west** (left) door. |
| **La Mariposa** | Wakes up on Night 2. Butterfly-cape hero who heads for your **east** (right) door. |
| **El Tornado** | Lurks in the **storage closet** (CAM 6). He only creeps forward while you are *not* watching him. Once he's ready he charges one of the doors. |

Lights show you who is standing in a doorway. A closed door sends them back. A wrong guess,
or an open door, is a jumpscare.

## Power

Doors, lights and the camera monitor all drain power, and the more you use, the faster it goes.
El Tornado banging on a closed door costs extra. If the power hits **0%**, the doors open, the
lights die and a music box starts to play...

## Controls

| Key | Action |
|---|---|
| `A` / `D` | Toggle the left / right door |
| `Q` / `E` | Toggle the left / right hallway light |
| `Space` | Open / close the camera monitor |
| `1`-`6` | Switch camera (while the monitor is up) |
| `M` | Silence the phone-call subtitles |
| `Esc` | Pause |
| `F11` | Fullscreen |

Everything is also clickable with the mouse.

## Run it from source

```bash
python -m pip install -r requirements.txt
python main.py
```

Needs Python 3.10+. Your progress (the furthest night reached) is saved to
`~/.superhero_house_save.json`.

## Get the Windows `.exe`

**Automatic (GitHub Actions):** every push to `main` runs the tests and builds
`SuperheroHouse.exe`.

* Open the repo's **Actions** tab, click the latest run, and download **SuperheroHouse-windows**
  from *Artifacts*.
* To publish a downloadable **Release**, push a version tag:
  ```bash
  git tag v1.0.0
  git push origin v1.0.0
  ```
  The workflow attaches `SuperheroHouse.exe` to the new release automatically.

**Manually on Windows:** double-click `build_exe.bat`. The exe appears in `dist\`.

> Windows SmartScreen may warn about the exe because it isn't code-signed. That's normal for
> small indie builds: click *More info* then *Run anyway*.

```
art.py        all drawing: office, cameras, characters, jumpscares
audio.py      synthesized sound effects

```
